Behind the Scenes

為什麼選擇「小」模型？

為什麼要做地端模型？

在醫療與公務體系中，「資訊安全」與「隱私保障」永遠是第一順位。若將人事法規或個人提問傳送至外部雲端（如 ChatGPT），總是存在著資安疑慮。因此我們採用了小巧的地端模型，讓推論完全在您的瀏覽器內執行。此外，也鼓勵院外人士或同仁在家使用。

小模型的挑戰：幻覺與記憶限制

然而，魚與熊掌難以兼得。僅有 1.9GB 的小模型，其內建的世界知識庫無法與千億參數的雲端巨獸相比。當被問到複雜的人事法規時，它很容易產生「幻覺 (Hallucination)」，同時在處理長文本或多輪對話時，也容易「遺忘」前提條件。

神隊友：混合式模糊檢索 (Hybrid Fuzzy Search)

為了解決上述痛點，我們為小模型打造了檢索增強生成 (RAG) 架構：

1. 文本清洗前處理

過濾標點符號與全半角差異，讓問題精準對齊。

2. 關鍵字加權

命中人工定義標籤即給予高分權重，確保精準度。

3. 雙連字 (Bigram) 容錯

拆解雙字組合，即使打錯字也能模糊比對成功！

4. AI 扮演潤飾專家

精準撈出 FAQ 條文後，小模型純粹進行閱讀理解與文字潤飾，大幅降低幻覺！
