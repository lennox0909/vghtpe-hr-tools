開發小故事

為什麼選擇「小」模型？

為什麼要做地端模型？

在醫療與公務體系中，「資訊安全」與「隱私保障」永遠是第一順位。若將人事法規或個人提問傳送至外部雲端（如 ChatGPT），總是存在著資安疑慮。因此我們採用了小巧的地端模型，讓推論完全在您的瀏覽器內執行。

此外，人事室的 FAQ 資訊是對外公開的，我們也非常鼓勵院外人士或同仁在家使用。如果您使用私人的電腦，或是具備較好硬體效能的筆電，將能獲得更快速、更極致的 AI 查詢體驗！

小模型的挑戰：幻覺與記憶限制

然而，魚與熊掌難以兼得。僅有 1.9GB 的小模型，其內建的世界知識庫無法與千億參數的雲端巨獸相比。當被問到複雜的人事法規時，它很容易產生「幻覺 (Hallucination)」，給出看似合理卻錯誤的答案；同時，它在處理長文本或多輪對話時，也容易「遺忘」前提條件。

神隊友：混合式模糊檢索 (Hybrid Fuzzy Search)

為了解決上述痛點，我們不依賴龐大的伺服器向量庫，而是為小模型打造 「混合式模糊檢索」 系統結合 RAG (檢索增強生成) 架構：

1. 文本清洗前處理

過濾標點符號與全半角差異，讓「請假規定？」與「請假規定」精準對齊。

2. 精準與關鍵字加權

若命中人工定義標籤（如：特休），系統即給予高分權重，確保精準度。

3. 雙連字 (Bigram) 容錯

將問題拆解為雙字組合（如：「生理假」切成「生理、理假」），即使打錯字也能模糊比對成功！

4. AI 扮演潤飾專家

演算法撈出最精準的 FAQ 條文後，小模型純粹扮演「閱讀理解與文字潤飾」的角色，大幅降低 AI 幻覺！
