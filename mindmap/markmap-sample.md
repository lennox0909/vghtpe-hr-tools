# 歡迎使用心智圖編輯器

## 什麼是 Markmap？
- Markmap 是一個可以將 Markdown 語法轉換為**心智圖**的開源工具
- 結合了 Markdown 的易讀性與心智圖的視覺化優勢

## 核心特色
- **即時預覽**：左側編輯，右側立即顯示結果
- **呈現多種資料格式**
  - **粗體** ~~刪除記號~~ *斜體* ==醒目標示==
  - `inline code`
  - [x] 勾選
  -
    ```javascript
    console.log('hello, JavaScript')
    ```
    
  - 
    | 表格 | Price |
    |-|:-:|
    | Apple | 4 |
    | Banana | 2 |

  - ![圖片](./Taipei_Veterans_General_Hospital_Emblem.svg)
  
  - **支援 LaTeX 數學公式**
    - **行內公式** $E = mc^2$ 與**區塊公式** $$x = \frac{-b \pm \sqrt{b^2-4ac}}{2a}$$
    
    - **自訂公式範例**：$$W_{\text{total}} = \frac{\text{月薪}}{240} \times \left(\frac{4}{3}H_1 + \frac{5}{3}H_2\right)$$
    
    - **統計常態分配機率密度**：$$f(x) = \frac{1}{\sigma\sqrt{2\pi}} e^{-\frac{1}{2}\left(\frac{x-\mu}{\sigma}\right)^2}$$
    
    - **線性代數矩陣排版**：$$\mathbf{A} = \begin{bmatrix} a_{11} & a_{12} \\ a_{21} & a_{22} \end{bmatrix}$$

- **多種匯出格式**
  - TXT 純文字原始檔
  - SVG 向量圖
  - **可互動的 HTML 網頁**
